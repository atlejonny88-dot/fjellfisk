Personvernerklæring for Arctic Hardanger

Sist oppdatert: 16. juni 2026

1. Om appen

Arctic Hardanger er en intern drifts- og produksjonsapp for registrering og oppfølging av landbasert fiskeoppdrett.

Appen brukes til å registrere og vise driftsdata som blant annet kar, fisketall, dødelighet, fôr, temperatur, snittvekt, produksjonsrapporter og brukerroller.

2. Hvilke opplysninger samles inn?

Appen kan behandle folgende opplysninger:

  • E-postadresse for innlogging
  • Brukerrolle, for eksempel admin, ansatt eller leser
  • Status for bruker, for eksempel aktiv eller deaktivert
  • Produksjonsdata registrert i appen, som fisketall, fôr, dødelighet, temperatur, snittvekt og notater
  • Tidspunkt for registreringer

Appen samler ikke inn betalingsinformasjon, posisjonsdata, kontakter, bilder fra telefonen, helseopplysninger eller annonseringsdata.

3. Hvorfor behandles opplysningene?

Opplysningene brukes for å:

  • Gi brukere tilgang til appen
  • Skille mellom ulike brukerroller
  • Registrere og følge opp produksjon
  • Lage historikk og rapporter
  • Sikre at bare godkjente brukere får tilgang
  • Hindre at deaktiverte brukere får brukt appen

4. Lagring av data

Data lagres i Firebase-tjenester fra Google, blant annet Firebase Authentication og Cloud Firestore.

Firebase Authentication brukes til innlogging.

Cloud Firestore brukes til lagring av brukerroller, produksjonsdata, kar, seksjoner, historikk og rapportgrunnlag.

5. Deling av data

Data selges ikke til tredjeparter.

Data brukes ikke til annonsering.

Data deles ikke offentlig.

Data kan behandles av tekniske leverandører som er nødvendige for at appen skal fungere, for eksempel Firebase/Google Cloud.

6. Tilgang og roller

Tilgang til appen styres med brukerroller:

  • Admin kan administrere brukere og data
  • Ansatt kan registrere og lese driftsdata
  • Leser kan lese data, men ikke endre produksjonsdata

Deaktiverte brukere mister tilgang til appen.

7. Sikkerhet

Appen bruker Firebase Authentication for innlogging og Firestore-regler for tilgangskontroll.

Kun innloggede og godkjente brukere skal ha tilgang til data i appen.

8. Hvor lenge lagres data?

Produksjonsdata og historikk lagres så lenge de er nødvendige for drift, dokumentasjon og intern oppfølging.

Brukerdata kan slettes eller deaktiveres når brukeren ikke lenger skal ha tilgang.

9. Dine rettigheter

Brukere kan kontakte appansvarlig for å be om innsyn, retting eller sletting av personopplysninger der dette er relevant.
